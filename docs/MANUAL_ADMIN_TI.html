Consolahttp://192.0.2.10:8080/login

Listener192.0.2.10:8080 (no comodín).
FirewallTCP 8080, perfil Domain, origen 192.0.2.0/24.

Secreto sesiónC:\ProgramData\MesaSoporteS6\lan-session-secret.txt, ACL SYSTEM/Administradores.
HTTP no cifra datos. El piloto solo es para la LAN confiable de la unidad. No usar en Internet, redes públicas ni sedes/VLAN no autorizadas. Para otra subred se requiere TLS institucional y procedimiento de migración.

Consola y flujo de tickets

  1. Abra /login e inicie sesión con una cuenta autorizada.
  2. La consola en /admin obtiene tickets desde SQLite.
  3. Busque/filtre por texto, estado o categoría y abra el detalle.
  4. Cambie estado/asignación y guarde notas; confirme respuesta exitosa del servidor.

Estados aceptados: Abierto, En Proceso, En Espera, Resuelto y Cancelado. Radicados: S6-AAAA-NNNNNN.

Límites actuales

  • Inventario, directorio de agentes y algunas preferencias siguen en el navegador administrador y no son multiusuario centralizados.
  • Las imágenes JPEG, PNG y WebP quedan asociadas al ticket y se consultan desde el detalle administrativo. El backend limita cada imagen a 900 KB y el total por ticket a 5 MB.
  • Las notificaciones por correo requieren un relay SMTP configurado en el servidor; siguen pendientes el SLA calculado en backend, la gestión/restablecimiento de usuarios y la consulta de estado autoservicio.
  • database_schema.sql es legado; el esquema activo lo inicializa server.py.

No anuncie funciones pendientes como activas. No guarde tokens OAuth, claves SMTP ni contraseñas de dominio en el navegador o tickets.

Cuentas administrativas

No existe cuenta/contraseña predeterminada. Para crear un administrador nuevo, use PowerShell autorizado en la raíz del proyecto:

Set-Location 'D:\HELP DESK TELEMATICA'
.\.venv\Scripts\python.exe server.py create-admin

El comando solicita usuario y contraseña (mínimo 14 caracteres) sin eco. Los hashes usan PBKDF2-HMAC-SHA256 con salt. No pegue contraseñas en chat, archivos o documentación. La consola no implementa recuperación/desactivación de cuentas; no modifique SQLite sin backup y autorización.

Tarea persistente

La tarea MesaSoporteS6-LAN corre como SYSTEM al arrancar Windows, tiene un retraso aleatorio de hasta 30 segundos, ignora instancias duplicadas, no tiene límite de ejecución y reintenta cinco veces cada minuto.

Get-ScheduledTask -TaskName MesaSoporteS6-LAN
Get-ScheduledTaskInfo -TaskName MesaSoporteS6-LAN
Get-NetTCPConnection -State Listen -LocalPort 8080
Invoke-WebRequest 'http://192.0.2.10:8080/' -UseBasicParsing

Normal: la tarea está Running, el listener pertenece a 192.0.2.10:8080 y el portal devuelve HTTP 200.

Restart-ScheduledTask -TaskName MesaSoporteS6-LAN

Detención temporal:

Stop-ScheduledTask -TaskName MesaSoporteS6-LAN
Get-NetTCPConnection -State Listen -LocalPort 8080 -ErrorAction SilentlyContinue

Compruebe que desaparezca el listener. No arranque una instancia manual mientras la tarea esté activa. La regla permanece para que el próximo arranque funcione. No borre el secreto: hacerlo invalida sesiones.

Firewall y archivos

Get-NetFirewallRule -DisplayName MesaSoporteS6-LAN-HTTP | Get-NetFirewallAddressFilter
Get-NetFirewallRule -DisplayName MesaSoporteS6-LAN-HTTP | Get-NetFirewallPortFilter

Debe ser entrada TCP 8080, perfil Domain y origen 192.0.2.0/24. No use Any, no abra 8080 a otras sedes y no enlace Waitress a 0.0.0.0. La tarea valida la IP privada, el consentimiento HTTP y la regla antes de servir.

La SQLite está protegida por ACL SYSTEM/Administradores; el secreto también. No comparta `instance` por SMB ni dé acceso al grupo general de usuarios. El secreto debe ser persistente para que sesiones sobrevivan reinicios.

Backup de tickets

SQLite utiliza WAL. Detenga la tarea y confirme que no haya listener antes de una copia coherente:

Stop-ScheduledTask -TaskName MesaSoporteS6-LAN
Get-NetTCPConnection -State Listen -LocalPort 8080 -ErrorAction SilentlyContinue

Use la API de backup de SQLite:

@'
import sqlite3
source = sqlite3.connect(r"D:\HELP DESK TELEMATICA\instance\helpdesk.sqlite3")
backup = sqlite3.connect(r"D:\Backups\helpdesk-YYYYMMDD.sqlite3")
source.backup(backup)
backup.close()
source.close()
'@ | .\.venv\Scripts\python.exe -

Cifre el backup con herramienta aprobada, ACL mínima y retención definida. Verifique PRAGMA integrity_check (esperado: ok). Reinicie con Start-ScheduledTask -TaskName MesaSoporteS6-LAN.

Incidentes frecuentes

  • Tarea no inicia: revise LastTaskResult, IP activa, puerto libre, venv, ACL y secreto.
  • Otro equipo no conecta: compruebe que pertenezca a la subred, perfil Domain, firewall y ruta de VLAN.
  • Portal abre y el envío falla: valide API mismo origen, SQLite con escritura y límite de 10 envíos/IP/10 min.
  • Se requiere otra unidad: no amplíe el HTTP; siga el manual de migración y exija TLS institucional.
